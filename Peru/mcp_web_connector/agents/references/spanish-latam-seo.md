# criterios para seo en espanol y latam

## localizacion

- Adaptar terminos al pais del usuario. Ejemplos: cotizar, solicitar demo, contratar, proveedor, empresa, solucion, servicio gestionado.
- Evitar traducciones literales de ingles si el mercado usa otro termino.
- Incluir pais, ciudad o distrito solo cuando aporte relevancia real y exista cobertura o capacidad comercial.
- Usar moneda, unidades, horarios y canales locales cuando el contenido sea transaccional.

## tono recomendado

- Para B2B: directo, consultivo, orientado a continuidad, costos, seguridad, soporte, SLA, ROI y riesgo operativo.
- Para ecommerce: claro, comparativo, orientado a stock, envio, garantias, precio, compatibilidad y reseñas.
- Para servicios locales: confianza, cercania, ubicacion, horarios, experiencia, reseñas y llamada/WhatsApp.

## paginas comerciales

Una landing en espanol para LatAm debe explicar:

- que se ofrece;
- para quien es;
- que problema resuelve;
- diferenciadores concretos;
- cobertura o condiciones;
- proceso de contratacion;
- pruebas de confianza;
- preguntas frecuentes;
- CTA claro.

## errores frecuentes

- usar nombres internos o anglicismos como unica keyword cuando el cliente busca terminos descriptivos.
- crear muchas paginas por ciudad sin contenido unico ni presencia real.
- traducir contenido global sin casos, legislacion, moneda o contexto local.
- escribir articulos informativos que no enlazan a una pagina comercial.
- repetir la misma keyword en titles, H1 y texto sin mejorar la respuesta al usuario.

## Peru

Cuando el mercado sea Peru, considerar modificadores naturales como Peru, Lima, provincias, cobertura nacional, empresas peruanas, soporte local, facturacion local, SLA, fibra optica, cotizacion, RUC, sectores como mineria, logistica, retail, educacion, salud, banca y gobierno si aplican.
